# i3 na sessão LXQt (X11)

> **Desativado.** O i3 saiu do build (`modules/i3.nix` comentado em
> `hosts/laptop/default.nix`) e a sessão LXQt voltou para o Openbox, com tiling via
> cortile. Ver `docs/cortile.md`. Este documento fica como referência para reativação.

O gerenciador de janelas da sessão **LXQt** é o i3. O LXQt continua cuidando
do painel (`lxqt-panel`, que também faz de barra), do gerenciador de arquivos,
da energia, das notificações e dos atalhos de volume e brilho (`lxqt-globalkeys`).

## Onde fica cada parte

| Parte | Arquivo |
|---|---|
| Instalação do i3 | `modules/i3.nix` (`services.xserver.windowManager.i3`) |
| Escolha do WM pelo LXQt | `window_manager=i3` em `~/.config/lxqt/session.conf` |
| Configuração do i3 | `dotfiles/i3/config`, linkada em `~/.config/i3/config` |

## Como alterar depois

1. Edite `dotfiles/i3/config`.
2. Aplique com `update`.
3. No i3, recarregue com `$mod+Shift+c`.

## Atalhos principais (`$mod` = tecla Windows)

| Atalho | Ação |
|---|---|
| `$mod+Enter` | Abre o Alacritty |
| `$mod+d` | Runner do LXQt (executar programas) |
| `$mod+e` | Gerenciador de arquivos (pcmanfm-qt) |
| `$mod+Shift+q` | Fecha a janela |
| `$mod+h/j/k/l` ou setas | Move o foco |
| `$mod+Shift+h/j/k/l` | Move a janela |
| `$mod+b` / `$mod+v` | Divide na horizontal / vertical |
| `$mod+f` | Tela cheia |
| `$mod+Shift+space` | Alterna flutuante |
| `$mod+s` / `$mod+w` / `$mod+t` | Layout empilhado / abas / alternar divisão |
| `$mod+1` … `$mod+9` | Vai para a área de trabalho |
| `$mod+Shift+1` … `$mod+Shift+9` | Envia a janela para a área de trabalho |
| `$mod+Shift+c` | Recarrega a configuração |
| `$mod+Shift+r` | Reinicia o i3 |
| `$mod+Shift+e` | Diálogo de sair do LXQt |

## Problemas conhecidos (i3 + LXQt)

- **Atalhos com a tecla Super:** o `lxqt-globalkeys` tinha atalhos próprios em
  `Meta+0…9` (ativar tarefa da barra) e `Super_L` (menu principal). Eles disputavam
  as mesmas combinações do i3. Foram removidos de `dotfiles/lxqt/globalkeyshortcuts.conf`.
  Para voltar algum deles, edite o arquivo e rode `lxqt-apply` e `lxqt-globalkeysd`.
- **Painéis em mosaico:** o i3 não trata o `lxqt-panel` como dock. Ele ocupa uma
  linha do mosaico, e não aceita flutuar porque a janela tem tamanho fixo e não
  recebe foco. Por isso a largura configurada no LXQt (ex.: 42%) não tem efeito:
  o painel sempre ocupa 100%.
- **Auto-hide do painel:** não funciona no i3. O LXQt usa `_NET_WM_STATE_BELOW`
  para esconder o painel, e o i3 não suporta esse atalho (issue i3/i3#4529).
- **Área de trabalho do pcmanfm-qt:** é uma janela em mosaico que ocupava uma
  coluna vazia com o wallpaper. A regra em `dotfiles/i3/config` a manda para o
  scratchpad (`$mod+minus` mostra ou esconde). O fundo sólido vem de `xsetroot`.

Se a largura e o auto-hide forem essenciais, as alternativas são: usar o `i3bar`
no lugar do `lxqt-panel` (o i3bar tem `mode hide`, mas perde a bandeja e o menu do
LXQt), ou voltar ao Openbox, que trata painéis e auto-hide corretamente.

## Observações

- Não há barra do i3 (`bar`). A barra é o `lxqt-panel`.
- Os atalhos de volume, brilho e captura de tela continuam no `lxqt-globalkeys`.
  Como a sessão é X11, eles funcionam sem reconfiguração.
- O Hyprland saiu do build (`modules/hyprland.nix` está desativado em
  `hosts/laptop/default.nix`). Os arquivos continuam no repositório; para voltar,
  reative o import e restaure o link de `hypr/hyprland.lua` em `modules/home.nix`.
